# Enterprise Data & Analytics Project Intake Form

This repository contains a standalone web form for the Enterprise Data & Analytics Project Intake and Requirements Framework.

## What it includes

- A responsive intake form covering request details, business need, data assessment, ownership, governance, architecture, security, reporting, development, testing, risks, dependencies, stakeholders, approvals, and status.
- Decision-matrix logic that calculates required teams from selected intake answers.
- A review/export summary intended to support handoff into Word, Dataverse notes, Planner, Jira, Azure DevOps, or Power Automate.
- No external runtime dependencies.

## Run locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
